# Student Project Timestamp System (Blockchain)
Blockchain-based system for secure student project timestamping
This project ensures secure and tamper-proof timestamping of student projects using blockchain technology.

## Features
Immutable timestamp storage
Transparent verification
Decentralized system

## Technologies
Solidity
Web3.js
MetaMask

## How to Run
1. Deploy contract using Remix
2. Connect MetaMask
3. Run frontend
